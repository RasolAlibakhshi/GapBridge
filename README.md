# Gap Bridge 2.0

<div dir="rtl">

**پل امن بین چت [gapgpt.app](https://gapgpt.app) و فایل‌ها، مرورگر و ترمینال سیستم شما.**

برنامهٔ دسکتاپ Electron به‌همراه افزونهٔ Chrome (Manifest V3) که به مدل زبانی اجازه می‌دهد، با دستور و تأیید شما، روی پوشه‌های مجاز فایل بخواند و بنویسد، مرورگر را کنترل کند و دستور اجرا کند.

> **درباره‌ی این پروژه:** این پروژه به‌صورت **وایب‌کدینگ (Vibe Coding)** و با کمک هوش مصنوعی ساخته شده است. کد را بخوانید، تست کنید و قبل از استفاده در محیط کاری، ریسک‌ها را در بخش [امنیت](#امنیت) بررسی کنید.

## نصب سریع

**پیش‌نیاز:** Node.js نسخهٔ LTS

```bash
npm install
npm start
```

سپس:

1. **افزونه:** در Chrome به `chrome://extensions` بروید، **Developer mode** را روشن کنید، روی **Load unpacked** بزنید و پوشهٔ `extension` را انتخاب کنید.
2. **توکن:** در برنامه روی «کپی توکن» بزنید، روی آیکون افزونه کلیک کنید، توکن را بچسبانید و ذخیره کنید. باید «وصل شد» نمایش داده شود.
3. **پوشه‌ها:** یک یا چند پوشهٔ مجاز اضافه کنید. چت فقط داخل این پوشه‌ها کار می‌کند.
4. **راهنما:** «کپی دستورالعمل» را بزنید و در ابتدای یک گفتگوی جدید در gapgpt.app بفرستید.

## نصب برای توسعه

```bash
npm install          # نصب وابستگی‌ها و ساخت node-pty برای Electron (postinstall)
npm start            # اجرای برنامه
npx electron-rebuild -f -w node-pty   # ساخت دستی node-pty، در صورت نیاز
```

- `node-pty` اختیاری است. اگر ساخت شکست بخورد، نصب متوقف نمی‌شود و ترمینال به حالت Pipe می‌رود.
- برای ساخت node-pty در ویندوز به **Visual Studio Build Tools** (با «Desktop development with C++») و **Python** نیاز است.

## ساخت فایل نصبی

```bash
npm run dist:win     # ویندوز: Setup.exe (NSIS) و Portable.exe ← خروجی در dist/
npm run dist:linux   # لینوکس: AppImage و deb
npm run dist:all     # هر دو (ساخت ویندوز روی لینوکس به wine نیاز دارد)
```

- ساخت `.exe` بهتر است روی ویندوز انجام شود.
- پوشهٔ `extension` در داخل برنامهٔ نصب‌شده (`resources/extension`) کپی می‌شود.
- آیکون: `build/icon.png` و `build/icon.ico` (حداقل ۲۵۶×۲۵۶ برای ویندوز).

### امضای کد (اختیاری)

گواهی را داخل `package.json` نگذارید. electron-builder آن را از متغیرهای محیطی می‌خواند:

```bash
CSC_LINK=<مسیر یا base64 فایل .p12>
CSC_KEY_PASSWORD=<رمز>
# بدون امضا حتی اگر گواهی پیدا شود:
# CSC_IDENTITY_AUTO_DISCOVERY=false
```

بدون امضا، SmartScreen در ویندوز هشدار نشان می‌دهد.

## امنیت

Gap Bridge دسترسی واقعی به سیستم شما می‌دهد. مدل پیش‌فرض این است:

- **فقط داخل پوشه‌های مجاز:** مسیرها با بررسی `..` و symlink کنترل می‌شوند.
- **تأیید برای کارهای تغییردهنده:** نوشتن، ویرایش، حذف، اجرای دستور، ضمیمه، دانلود و کارهای مرورگر هر بار دیالوگ تأیید دارند، مگر «اجرای خودکار» را روشن کرده باشید.
- **دستورهای خطرناک همیشه تأیید می‌خواهند:** مثل `format`، `rm -rf`، `del /s`، حتی با اجرای خودکار.
- **حذف بزرگ:** حذف بیش از حدود ۲۰٬۰۰۰ فایل یا ۵۰۰MB، تأیید اجباری دارد و بازگردانی برای آن ثبت نمی‌شود.
- **شبکه:** سرور فقط روی `127.0.0.1` است، فقط به درخواست‌های افزونه (Origin) پاسخ می‌دهد و با توکن احراز هویت می‌شود.
- **دانلود:** آدرس‌های محلی و خصوصی مسدودند، ریدایرکت‌ها محدودند و حجم و زمان دانلود سقف دارد.

> **توجه:** ترمینال به پوشه‌های مجاز محدود نیست و با دسترسی کامل حساب کاربری شما اجرا می‌شود. محدودیت پوشه فقط برای پوشهٔ شروع است. متن هر دستور را قبل از تأیید بخوانید.

## ترمینال

بخش «ترمینال» در برنامه یک شل واقعی باز می‌کند (ویندوز: `cmd.exe`، لینوکس/مک: `$SHELL`).

- **حالت PTY:** اگر `node-pty` ساخته شده باشد، ترمینال کامل است (رنگ، پرامپت واقعی، Ctrl+C واقعی).
- **حالت Pipe:** اگر `node-pty` در دسترس نباشد، برنامه به‌صورت خودکار به این حالت می‌رود. ویرایش خط، تاریخچه (↑/↓) و پرامپت تقریبی را خود برنامه فراهم می‌کند.

---

## مرورگر (CDP)

مرورگر را از بخش «مرورگر Chromium» اجرا کنید. Chrome، Edge، Brave یا Chromium به‌صورت خودکار پیدا می‌شود (یا «انتخاب دستی»).

- پروفایل جداگانه در پوشهٔ داده‌های برنامه (`chromium-profile`) است؛ رمزها و حساب‌های پروفایل اصلی شما در آن نیست.
- پورت دیباگ `9222` فقط روی `127.0.0.1` باز می‌شود.
- با بستن Gap Bridge مرورگر هم بسته می‌شود.
- اجرای دستی (نمونهٔ ویندوز):
  ```
  chrome.exe --remote-debugging-port=9222 --user-data-dir="%TEMP%\gap-bridge-browser"
  ```

کنترل به صفحه‌های باز در این مرورگر دسترسی دارد. `browser_eval` کد JavaScript را در زمینهٔ همان صفحه اجرا می‌کند؛ فقط با صفحه‌ها و کدهایی کار کنید که خودتان مجاز می‌دانید.

## به‌روزرسانی

- به‌روزرسانی خودکار **پیش‌فرض خاموش** است. آدرس سرور (فقط `https`) را در بخش «به‌روزرسانی» وارد کنید.
- برنامه قبل از دانلود و قبل از نصب از شما سؤال می‌کند.
- NSIS و AppImage به‌روز می‌شوند. نسخهٔ Portable، deb و حالت توسعه خودکار به‌روز نمی‌شوند.
- بعد از هر به‌روزرسانی، افزونه را در `chrome://extensions` دوباره بارگذاری کنید. مسیر ثابت افزونه از دکمهٔ «باز کردن پوشهٔ افزونه» در `userData/extension` در دسترس است.

## عیب‌یابی

- **ساخت `.exe` با خطای `Cannot create symbolic link`:** Developer Mode ویندوز را روشن کنید یا CMD را با Run as administrator اجرا کنید، سپس پوشهٔ `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign` را پاک کنید.
- **node-pty نصب نشد:** Visual Studio C++ Build Tools را نصب کنید و پوشهٔ پروژه را به مسیری بدون فاصله منتقل کنید. برنامه بدون آن هم کار می‌کند (حالت Pipe).
- **افزونه وصل نمی‌شود:** توکن را دوباره کپی کنید و افزونه را بارگذاری دوباره کنید.
- **لاگ:** بخش «لاگ» برنامه پیام‌های فرایند اصلی، رابط و افزونه را نشان می‌دهد. با «کپی» می‌توانید لاگ فیلترشده را همراه نسخه و سیستم‌عامل برای گزارش باگ کپی کنید (توکن و مسیر خانه حذف می‌شوند).
- **ظاهر سایت تغییر کرده:** تشخیص کادر ورودی و دکمهٔ ارسال در `extension/content.js` (تابع‌های `findInput` و `sendMessage`) را تنظیم کنید.

## محدودیت‌های شناخته‌شده

- جست‌وجوی معنایی فعلاً محلی و واژگانی/n-gram است (بدون Ollama یا OpenAI).
- کلیک و تایپ با ref، تصویر حاشیه‌نویسی‌شده و `selectors.json` راه‌دور هنوز پیاده نشده‌اند.
- نمایشگر ترمینال شبیه‌ساز کامل نیست؛ برنامه‌های تمام‌صفحه (vim، htop، less) درست نمایش داده نمی‌شوند. متن راست‌به‌چپ ممکن است جابه‌جا دیده شود.
- در حالت Pipe، برنامه‌های تعاملی که TTY می‌خواهند (مثل `ssh`) کار نمی‌کنند.
- تشخیص «آمادگی پرامپت» بر اساس نشانه‌های رابط وب است و ممکن است با تغییر سایت نیاز به تنظیم داشته باشد.
- **تست:** بخش‌های `lib` با Node تست شده‌اند. اجرای واقعی روی Electron، Chrome/Edge، ضمیمه در gapgpt، دانلود، سینی سیستم و منوی ویندوز هنوز به‌صورت کامل تست نشده‌اند.
